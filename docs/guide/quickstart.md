# 快速上手（平台使用指南）

> 本页面向**首次使用平台的使用者**：从创建产品到看到设备数据的最短路径。设备端报文格式请参考 [协议总览](/guide/overview)。

---

## 0. 准备

- 已部署的平台地址（自建部署见仓库 README「快速开始」，或使用运维提供的地址）
- 一个平台账号（登录页可自助注册；若关闭注册请联系管理员开户）

登录后，平台概览页会显示**「快速上手」四步引导卡**，完成的步骤会自动打勾，三步都就绪后自动消失（也可点「不再显示」）。

## 1. 创建产品

**产品 = 同一类设备的模板**，定义这批设备怎么连接、数据长什么样。

进入 **产品管理 → 创建产品**，关键选择：

| 配置项 | 怎么选 |
|---|---|
| 接入协议 | 智能硬件选 **MQTT**（推荐）；串口/DTU 透传设备选 **TCP**；弱网络一次性上报选 **HTTP** |
| 数据模式 | 设备能发 JSON 选 **物模型**（推荐）；发私有二进制选 **透传**（配 JS 解析脚本）；PLC/仪表选 **Modbus**（平台主动轮询） |
| 密钥模式 | 设备先注册后连接选 **一机一密**；产线免预注册选 **一型一密**（凭 ProductSecret 动态注册） |

> 注意：**接入协议与数据模式创建后不可修改**；TCP/Modbus 需要新建产品测试。

创建成功后记录 **ProductID**（形如 `p_xxxxxxxx`）。

## 2. 定义物模型（物模型产品）

物模型描述设备有哪些属性/事件/服务。进入产品详情 → **功能定义**：

1. 添加属性：标识符 `temperature`、名称 `温度`、数据类型 `float`、单位 `℃`、读写 `r`
2. 平台按物模型**校验并过滤**上报数据：未定义的属性不会进入实时数据与规则

也可以直接 **导入 TSL JSON**（支持从其他产品导出）。

- 透传产品：在 **数据解析** 中编写 `decode(bytes)` / `encode(obj)` JS 脚本，可用 hex 报文在线测试
- Modbus 产品：在 **点位表** 中配置从机号/功能码/地址/缩放，平台按采集组自动轮询

## 3. 添加设备

进入 **设备管理**（或产品详情 → 设备管理）→ 添加设备，输入设备名称（产品内唯一）。

创建后进入设备详情，查看/复制**设备三元组**：

```
ProductID     p_xxxxxxxx
DeviceName    sensor-001
DeviceSecret  6f2a...（点击"查看"显示）
```

批量开设备：产品详情 → 设备管理 → **批量导入**（一次最多 500 台）。
TCP 设备可配置**注册码**（IMEI/ICCID 等），连接时免三元组。

## 4. 验证设备连接

**方式一：平台内置模拟器**（无需硬件）

**开发工具 → 设备模拟器**：选择产品与设备建立会话，按物模型模板上报遥测、上报事件、接收下行指令。

**方式二：Node.js 模拟器**（真实 MQTT 链路）

```bash
cd tools/simulator
npm install
node simulator.js <productId> <deviceName> <deviceSecret> [broker]
```

**方式三：真实设备** 按 [MQTT 接入](/guide/mqtt) / [TCP-DTU 接入](/guide/tcp-dtu) / [HTTP 直传](/guide/http) 对接。

设备连接成功后：设备状态变**在线**（概览/列表实时刷新），详情页出现实时数据卡片。

## 5. 查看数据

设备详情 → **设备监控**：

- **实时数据**：属性卡片实时刷新（WebSocket 推送）
- **历史曲线**：1 小时 / 6 小时原始点；**24 小时 / 7 天 / 30 天自动切换为时间桶聚合**（曲线左上角会标注聚合粒度），右上角可导出 CSV
- **属性设置 / 服务调用 / 命令下发**：下行调试（只读账号不可见）
- **运行日志**：上下行报文、连接事件、错误分类检索

排查上报问题：**开发工具 → 消息轨迹**，按 TraceID 查看每条消息的 ingest/decode/store/rule 分阶段耗时与校验状态。
