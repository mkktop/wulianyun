# 错误码与响应参考

> 平台 API 采用统一响应信封。本文档汇总所有接入相关的响应结构、业务码与错误消息，供对接排障使用。

## 一、统一响应信封

**管理端 / OpenAPI 接口**统一返回 JSON：

```json
{ "code": 0, "msg": "ok", "data": { } }
```

| 字段 | 说明 |
|---|---|
| `code` | 业务码：`0` 成功；非 0 失败（值与 HTTP 状态码语义一致，见下表） |
| `msg` | 人类可读消息 |
| `data` | 成功时的数据；失败时通常不返回 |

**两个例外（注意区分）：**

1. **HTTP 直传端点**（`POST /api/v1/http/telemetry`）：使用真实 HTTP 状态码（200/401/403/400），`code` 与 HTTP 状态一致
2. **OpenAPI 签名鉴权失败**：返回 HTTP 401 + `{code: 401, msg: "..."}`

## 二、业务码

| code | 含义 |
|---|---|
| `0` | 成功 |
| `1` | 业务处理失败（失败消息见 `msg`） |
| `400` | 参数错误 / 业务规则不满足 |
| `401` | 未认证 / 签名错误 / 令牌失效 |
| `403` | 无权限（如查看者账号尝试写操作、设备已禁用） |
| `404` | 资源不存在（或无权访问，统一按不存在返回） |
| `500` | 服务端错误 |

> 业务失败通常返回 **HTTP 200 + 非零 `code`**（管理端/OpenAPI 统一信封）；仅鉴权失败与 HTTP 直传使用真实 HTTP 状态码。

## 三、设备相关

| code | msg | 触发条件 |
|---|---|---|
| 404 | `设备不存在` | 设备 ID 无效或不属于当前账号/应用 |
| 400 | `设备不在线` | 下发命令/服务调用时设备离线 |
| 400 | `命令必须是合法 JSON` | 透传命令请求体不是合法 JSON 对象 |
| 400 | `属性参数必须是非空 JSON 对象` | 属性设置 `params` 为空 |
| 400 | `服务标识符必填` | 服务调用缺少 `service` 字段 |
| 500 | `下发失败: <err>` | 下行通道不可用 |
| 500 | `更新影子失败` | 影子写入异常 |
| 400 | `产品和设备名称必填` | 创建设备缺少产品/设备名 |
| 404 | `产品不存在或未下放` | 产品不可见 |
| 400 | `该产品下设备名称已存在` | 产品内设备名重复 |
| 400 | `注册码已被占用` | 自定义注册码冲突 |
| 400 | `分组不存在或无权访问` | 设备移入不可见分组 |

## 四、物模型（TSL）相关

| code | msg | 触发条件 |
|---|---|---|
| 404 | `产品不存在` | 产品 ID 无效 |
| 400 | `参数错误` | 请求体非法 |
| 400 | `<属性/事件/服务>标识符和名称必填` | 缺 identifier 或 name |
| 400 | `<属性/事件/服务>标识符不能使用保留字: <id>` | 使用了保留字（见下） |
| 400 | `<属性/事件/服务>标识符重复: <id>` | 同类别内 identifier 重复 |
| 400 | `属性[<id>]数据类型非法: <value>` | dataType 不在支持集合内 |
| 400 | `属性[<id>]取值范围 min 不能大于 max` | min > max |
| 400 | `枚举属性[<id>]必须定义枚举项` | enum 类型缺 enumSpec |
| 400 | `事件[<id>]类型非法，应为 info/alert/fault` | event.type 非法 |
| 400 | `物模型文件过大（上限 8MB）` | 导入文件超 8MB |
| 400 | `JSON 格式错误: <err>` | 导入文件不是合法 JSON |

**保留字**（属性/事件/服务标识符禁用）：`set / get / post / property / event / time / value`

## 五、OTA 相关

| code | msg | 触发条件 |
|---|---|---|
| 400 | `产品ID必填` / `产品ID格式错误` | 固件上传缺少/非法的产品 ID |
| 400 | `版本号必填` | 固件上传缺少版本号 |
| 404 | `产品不存在` | 产品不可见 |
| 400 | `仅支持固件文件类型（bin/hex/img/zip/tar/gz/pack 等）` | 上传文件扩展名不在白名单 |
| 400 | `非法文件名` | 文件名清洗后仍非法 |
| 500 | `保存文件失败` / `写入文件失败` | 磁盘写入异常 |
| 404 | `固件不存在` | 固件 ID 无效 |
| 400 | `未找到有效设备（需与固件同属一个产品）` | 目标任务设备与固件产品不一致 |

## 六、OpenAPI 签名鉴权

以下均返回 **HTTP 401**：

| msg | 触发条件 |
|---|---|
| `缺少签名头 X-App-Key/X-Timestamp/X-Sign` | 三个签名头缺一 |
| `时间戳无效或已过期` | 与服务器时间差超过 ±5 分钟 |
| `AppKey 无效或已禁用` | AppKey 不存在或应用被停用 |
| `应用归属账号不存在` / `应用归属账号已禁用` | 应用归属用户被删除/禁用 |
| `签名错误` | HMAC 不匹配（method/path/body/时间戳任一不一致） |

## 七、HTTP 直传端点

`POST /api/v1/http/telemetry`（真实 HTTP 状态码）：

| HTTP | code | msg | 触发条件 |
|---|---|---|---|
| 401 | 401 | `missing X-Device-Token` | 缺少请求头 |
| 401 | 401 | `invalid token encoding` | Base64 解码失败 |
| 401 | 401 | `invalid token format` | 三元组非 3 段 |
| 401 | 401 | `auth failed` | 产品/设备不存在或密钥错误 |
| 403 | 403 | `device disabled` | 设备已禁用 |
| 400 | 400 | `read body failed` | 读取请求体失败 |

## 八、设备状态值

| 状态 | 含义 |
|---|---|
| `inactive` | 已创建未激活（未接入过） |
| `online` | 在线 |
| `offline` | 离线 |
| `disabled` | 已禁用（拒绝任何接入与上报） |

## 九、分页响应

列表接口统一返回 `data` 内：

```json
{ "total": 123, "list": [ ... ] }
```

- 分页参数：`page`（从 1 起）+ `size`（默认 10，上限 100）
- 历史遥测（`/devices/:id/history`）：无分页，用 `start`/`end`（毫秒）+ `limit`（默认 2000，上限 50000）
